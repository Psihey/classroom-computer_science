SQL — це англійська мова, тільки дуже сувора 🇬🇧

Сьогодні вчимося говорити з базою даних реченнями: вибирати лише потрібні стовпці, ставити умови (WHERE, AND, OR, >, <) і шукати за частиною слова (LIKE).

💡 Головна ідея

SQL придумали так, щоб запит читався як звичайне англійське речення. Якщо ти можеш сказати це англійською, ти майже написав SQL.

UAПокажи імена та прізвища клієнтів із Франції.
ENSelect first name, last name from customers where country is France.
SELECT FirstName, LastName FROM Customer WHERE Country = 'France';
⚠️ Але база — дуже сувора вчителька англійської: одна зайва кома, забута лапка чи помилка в назві стовпця, і вона тебе «не зрозуміє» (видасть помилку).

🧩 Граматика: порядок слів

Як в англійській (підмет → присудок → додаток), у SQL слова стоять у строгому порядку:

SELECT→ FROM→ WHERE→ ORDER BY→ LIMIT

Пунктирні частини необовʼязкові. Але якщо вони є, порядок саме такий. WHERE після ORDER BY — це помилка, як «Is France where country».

1️⃣ Вибираємо лише потрібні стовпці

Минулого разу ми писали SELECT *, тобто «покажи все». Але в таблиці Customer 13 стовпців, і більшість нам не потрібна.

ENSelect everything from customers.
SELECT * FROM Customer;
ENSelect first name, last name and country from customers.
SELECT FirstName, LastName, Country FROM Customer;
✏️ Стовпці перелічуємо через кому, як в англійському переліку. Після останнього коми немає. Порядок стовпців у запиті = порядок у результаті.
SELECT Name, Milliseconds, UnitPrice FROM Track;
SELECT Title FROM Album;

💬 Спитай клас: «Як англійською попросити тільки назви альбомів?»

2️⃣ WHERE — «де, за умови що»

WHERE — фільтр: залишає лише ті рядки, для яких умова правдива.

ЗнакАнглійськоюПриклад
=is, equalsCountry = 'Canada'
<>is notCountry <> 'USA'
>more thanUnitPrice > 1
<less thanMilliseconds < 60000
>=at leastTotal >= 20
<=at mostTotal <= 1
ENSelect name and price from tracks where price is more than 1.
SELECT Name, UnitPrice FROM Track WHERE UnitPrice > 1;
ENSelect name and city from customers where country is not USA.
SELECT FirstName, City FROM Customer WHERE Country <> 'USA';
⚠️ Текст — у лапках 'USA', числа — без лапок 1.
⚠️ = чутливий до великих і малих літер: 'usa' ≠ 'USA'. Перевірте разом із класом: WHERE Name = 'bohemian rhapsody' дасть 0 рядків.
⏱️ Нагадування: довжина треку зберігається в мілісекундах. 1 хв = 60 000 мс, 5 хв = 300 000 мс.

3️⃣ AND та OR — «і» та «або»

AND — мають виконатися обидві умови.
«Я піду гуляти, якщо сонячно і я зробив домашку.»
Результат менший: фільтр суворіший.
OR — достатньо хоча б однієї.
«Я їм піцу або бургер.»
Результат більший: фільтр мʼякший.
ENSelect tracks where genre is rock and length is more than 10 minutes.
SELECT Name, Milliseconds FROM Track
WHERE GenreId = 1 AND Milliseconds > 600000;
ENSelect customers where country is Brazil or country is Argentina.
SELECT FirstName, LastName, Country FROM Customer
WHERE Country = 'Brazil' OR Country = 'Argentina';
🚫 Типова помилка: WHERE Country = 'Brazil' OR 'Argentina'. Англійською так скажеш, а SQL не зрозуміє. Умову треба писати повністю з кожного боку.
🧠 Для сильних: AND «сильніший» за OR, як множення сильніше за додавання. Якщо змішуєш їх, став дужки: 
WHERE (GenreId = 1 OR GenreId = 3) AND Milliseconds > 600000

4️⃣ LIKE — «схожий на»

Коли ми не памʼятаємо назву точно, а знаємо лише її частину. % означає «будь-що, будь-якої довжини (навіть нічого)».

ШаблонАнглійськоюЗнайде
'Love%'starts with LoveLove Gun, Love Of My Life…
'%love'ends with loveWhole Lotta Love…
'%love%'contains loveбудь-де в назві
'_a%'second letter is a_ — рівно один будь-який символ
SELECT Name FROM Track WHERE Name LIKE 'Love%';     -- 27 треків
SELECT Name FROM Track WHERE Name LIKE '%love%';    -- 114 треків
SELECT FirstName FROM Customer WHERE FirstName LIKE '_a%';
✅ На відміну від =, LIKE не зважає на великі й малі літери (для англійських літер). '%love%' знайде і «Love», і «LOVE».
🪤 Пастка (покажіть наживо!): шукаємо пісні про дощ. 
SELECT Name FROM Track WHERE Name LIKE '%rain%';
Серед результатів — Crazy Train, My Poor Brain, Safety Training. LIKE шукає літери, а не зміст: «t-rain», «b-rain». Комп'ютер не знає, що таке дощ!

NOT LIKE — «не схожий на»:

SELECT Name FROM Track WHERE Name LIKE '%love%' AND Name NOT LIKE '%you%';

🗣️ Перекладай сам (усно з класом)

Читаю речення, клас перекладає на SQL. Натисніть, щоб побачити відповідь.

Select album titles from albums. 
SELECT Title FROM Album;
Покажи імʼя, прізвище і місто клієнтів із Канади. 
SELECT FirstName, LastName, City FROM Customer WHERE Country = 'Canada';
Select invoices where total is at least 20. 
SELECT * FROM Invoice WHERE Total >= 20;
Скільки клієнтів із Франції або Німеччини? 
SELECT COUNT(*) FROM Customer WHERE Country = 'France' OR Country = 'Germany';  -- 9
Select artists whose name starts with «The». 
SELECT Name FROM Artist WHERE Name LIKE 'The %';
Покажи треки коротші за 1 хвилину. 
SELECT Name, Milliseconds FROM Track WHERE Milliseconds < 60000;
🔎 Знайди клієнтів, у яких пошта на yahoo, але вони не з США. 
SELECT FirstName, Email, Country FROM Customer
WHERE Email LIKE '%yahoo%' AND Country <> 'USA';

🧾 Шпаргалка на дошку

SELECT стовпець1, стовпець2      -- що показати
FROM   Таблиця                 -- звідки
WHERE  умова1 AND/OR умова2;    -- за якої умови

-- умови:  =  <>  >  <  >=  <=   LIKE '%слово%'   NOT LIKE
-- текст у 'лапках', числа без лапок

🕵️ Музичні детективи: шукаємо лише те, що треба

Знову працюємо з базою музичного магазину Chinook. Сьогодні вибираємо потрібні стовпці, ставимо умови WHERE, AND, OR, >, < і шукаємо за частиною слова через LIKE. У кінці тебе чекає розслідування: фейковий плейлист і пісня-загадка.

🧰 Крок 0. Відкрий базу

Відкрий файл Chinook_Sqlite.sqlite з минулого уроку в DB Browser for SQLite (Ctrl+O) і перейди на вкладку Execute SQL. Запит запускається клавішами Ctrl+Enter.

Файлу немає? Завантажити Chinook_Sqlite.sqlite. Немає DB Browser? Відкрий sqliteonline.com → File → Open DB → обери файл.

⚠️ Нічого не зберігай і не видаляй. Сьогодні ми лише читаємо дані.
📌 Як працювати: ПОВТОРИ — перепиши запит руками (не копіюй!) і запусти. САМ — заміни ___ на потрібне або напиши запит сам. Відповіді записуй у бланк унизу.
📚 Нагадування: Track — пісні (Name, GenreId, Milliseconds, UnitPrice), Customer — клієнти (FirstName, LastName, City, Country, Email), Employee — працівники (FirstName, LastName, Title), Invoice — рахунки (Total — сума). Жанр Rock має GenreId = 1. 1 хвилина = 60 000 мс.

🕵️ 5. Розслідування 2 бали

5.1 🎧 Фейковий плейлист

Однокласник хвалиться: «Я зібрав плейлист тільки з пісень, які продаються в Chinook!» Але здається, він трохи прибрехав. Перевір кожну пісню і знайди ті, яких немає в магазині.

  • Bohemian Rhapsody
  • Stefania
  • Smells Like Teen Spirit
  • Shape Of You
  • Billie Jean
  • Despacito
  • Hotel California
  • Nothing Else Matters
SELECT Name FROM Track WHERE Name LIKE '%Stefania%';
-- порожній результат = такої пісні немає

💡 Чому тут краще LIKE '%…%', а не =? Подумай про великі й малі літери.

Які пісні фейкові? Запиши їхні назви.

5.2 🌧️ Пісня-загадка

До магазину пише покупець: «Я шукаю одну пісню, але не памʼятаю назви. Памʼятаю лише ось що…»

1️⃣
«У назві було слово rain (дощ)».
2️⃣
«Це був рок».
3️⃣
«Вона дуже довга, понад 8,5 хвилини».

Додавай підказки до запиту по одній (через AND) і щоразу записуй, скільки пісень залишилося.

SELECT Name, Milliseconds FROM Track
WHERE Name LIKE '___'
  -- AND ...
  -- AND ...;

Скільки пісень було після 1-ї, 2-ї і 3-ї підказки? Як називається пісня?

🤔 Після першої підказки подивись на назви уважно. Чи всі ці пісні справді про дощ? Чому вони потрапили в результат?

⭐ Бонус для найсильніших +3 бали

Б1(+1) Три сходи на небо. У магазині є кілька версій пісні Stairway To Heaven. Скільки їх і скільки хвилин (приблизно) триває найдовша?

Б2(+1) Пастка дужок. Запусти обидва запити. Чому числа такі різні? Який із запитів справді рахує «рок або метал, довші за 10 хвилин»?

SELECT COUNT(*) FROM Track WHERE GenreId = 1 OR GenreId = 3 AND Milliseconds > 600000;
SELECT COUNT(*) FROM Track WHERE (GenreId = 1 OR GenreId = 3) AND Milliseconds > 600000;

Б3(+1) Придумай свою загадку. Обери будь-яку пісню з бази і придумай 3 підказки, які разом ведуть рівно до однієї пісні (як у 5.2). Запиши підказки і запит. Дай загадку сусідові: чи розгадає він?
