SQL — це англійська мова, тільки дуже сувора 🇬🇧

Минулого разу ми дізналися, як стрімінги зберігають фільми в базах даних, і написали перші запити SELECT … FROM … WHERE … LIMIT. Сьогодні вчимося ставити базі точні запитання: вибирати потрібні стовпці й перейменовувати їх, рахувати на льоту, поєднувати умови (AND, OR, NOT, IN, BETWEEN) і шукати за частиною слова (LIKE).

💡 Головна ідея

SQL придумали в 1970-х, щоб із базою могли «говорити» не лише програмісти. Тому запит читається як англійське речення.

UAПокажи назви і тривалість серій, довших за 45 хвилин.
ENSelect name and length from tracks where length is more than 45 minutes.
SELECT Name, Milliseconds FROM Track WHERE Milliseconds > 2700000;
⚠️ Але база — дуже сувора вчителька англійської: зайва кома, забута лапка, помилка в назві стовпця, і вона «не зрозуміє» (видасть помилку). Читайте повідомлення про помилку: там зазвичай написано, що саме не так.

🧩 Граматика: порядок слів

SELECT→ FROM→ WHERE→ ORDER BY→ LIMIT

Пунктирні частини необовʼязкові, але порядок завжди такий. WHERE після ORDER BY — помилка, як «Is France where country».

1️⃣ Лише потрібні стовпці, AS та обчислення

SELECT * означає «покажи все». У таблиці Customer 13 стовпців, але зазвичай треба 2–3.

ENSelect first name, last name and country from customers.
SELECT FirstName, LastName, Country FROM Customer;
✏️ Стовпці перелічуємо через кому, після останнього коми немає. Порядок у запиті = порядок у результаті.

AS — дати стовпцю зрозумілу назву

ENSelect first name as «Імʼя», country as «Країна» from customers.
SELECT FirstName AS Імʼя, Country AS Країна FROM Customer;

Обчислення на льоту

Тривалість у базі зберігається в мілісекундах. Людині зручніше бачити хвилини, тому рахуємо прямо в запиті:

SELECT Name AS Назва,
       ROUND(Milliseconds / 60000.0, 1) AS Хвилини
FROM Track;
🧮 Пастка: Milliseconds / 60000 дасть 5, а / 60000.0 дасть 5.73. Ціле, поділене на ціле, у SQLite дає ціле. Покажіть обидва варіанти наживо.

ENSelect customers whose country is one of France, Germany, Poland.
SELECT FirstName, Country FROM Customer
WHERE Country IN ('France', 'Germany', 'Poland');
ENSelect tracks whose length is between 3 and 4 minutes.
SELECT Name FROM Track WHERE Milliseconds BETWEEN 180000 AND 240000;
⚠️ Текст пишемо в 'лапках', числа без лапок. = розрізняє великі й малі літери: 'usa' ≠ 'USA'. BETWEEN включає обидві межі.

IS NULL — «значення невідоме»

У деяких треків автор (Composer) не вказаний: там NULL, тобто «порожньо, невідомо». Це не нуль і не пробіл.

SELECT Name FROM Track WHERE Composer IS NULL;      -- правильно
SELECT Name FROM Track WHERE Composer = NULL;       -- 0 рядків! так не працює

3️⃣ AND, OR, NOT і дужки

AND: обидві умови. «Сонячно і є час». Результат менший.
OR: хоча б одна. «Піца або бургер». Результат більший.
SELECT Name, Milliseconds FROM Track
WHERE MediaTypeId = 3 AND Milliseconds > 2700000;   -- відео довші за 45 хв
🚫 WHERE Country = 'Brazil' OR 'Chile' — помилка. Англійською так кажуть, а SQL ні. Пишіть повністю: Country = 'Brazil' OR Country = 'Chile' або Country IN ('Brazil','Chile').
🧠 AND сильніший за OR, як множення сильніше за додавання: 2 + 3 × 4 = 14, а не 20. Тому: 
-- «драма, АБО (фантастика довша за 50 хв)»: зовсім не те, що хотіли
WHERE GenreId = 21 OR GenreId = 20 AND Milliseconds > 3000000
-- «(драма або фантастика) І довша за 50 хв»: правильно
WHERE (GenreId = 21 OR GenreId = 20) AND Milliseconds > 3000000
Правило: змішуєш AND і OR, то став дужки.

NOT перевертає умову: NOT Country = 'USA', NOT IN (…), NOT LIKE, IS NOT NULL.

4️⃣ LIKE — «схожий на»

Коли назву не памʼятаєш точно. % — будь-яка кількість будь-яких символів (навіть 0), _ — рівно один символ.

ШаблонАнглійськоюЗнайде
'Love%'starts withLove Gun, Love Of My Life…
'%love'ends withWhole Lotta Love…
'%love%'containsбудь-де в назві
'_a%'2nd letter is aMark, Daan, Hannah…
SELECT Name FROM Track WHERE Name LIKE '%love%';              -- 114
SELECT Title FROM Album WHERE Title LIKE '%Season%';          -- сезони серіалів?
✅ LIKE не зважає на регістр (для латиниці): '%lost%' знайде і «Lost», і «LOST».
🪤 Пастка (покажіть наживо!): 
SELECT Name FROM Track WHERE Name LIKE '%rain%';
Шукали пісні про дощ, а знайшли Crazy Train і My Poor Brain. LIKE шукає літери, а не зміст. Так само пошук «сезонів» знайде Vivaldi: The Four Seasons.

🗣️ Перекладай сам (усно з класом)

Покажи клієнтів із Канади, США або Бразилії (через IN). 
SELECT FirstName, Country FROM Customer WHERE Country IN ('Canada', 'USA', 'Brazil');
Select invoices where total is between 5 and 6. 
SELECT * FROM Invoice WHERE Total BETWEEN 5 AND 6;
Скільки клієнтів не вказали компанію? 
SELECT COUNT(*) FROM Customer WHERE Company IS NULL;
Select artists whose name starts with «The» but are not «The Who». 
SELECT Name FROM Artist WHERE Name LIKE 'The %' AND Name <> 'The Who';
🔎 Пошта на yahoo, але клієнт не з Франції й не з Німеччини. 
SELECT FirstName, Email, Country FROM Customer
WHERE Email LIKE '%yahoo%' AND Country NOT IN ('France', 'Germany');

5.2 🎬 Серія-загадка

У підтримку пише глядач: «Я дивився одну серію, але забув назву. Допоможіть знайти!»

1️⃣
«У назві було слово man».
2️⃣
«Це була саме серія (відео), а не пісня».
3️⃣
«Жанр: Drama».
4️⃣
«Довга, понад 44 хвилини».

Додавай підказки по одній через AND і щоразу записуй, скільки рядків залишилося.

SELECT Name, Milliseconds FROM Track
WHERE Name LIKE '___'
  -- AND ...;

Скільки рядків після кожної з 4 підказок? Як називається серія?

🤔 Після 3-ї підказки уважно переглянь назви. Одна з них насправді не про «man». Чому вона в результаті?

⭐ Бонус +3 бали

Б1(+1) Відео за ціною пісні. Усі серії коштують 1.99, але є одне відео за 0.99. Що це?

Б2(+1) Топ-3 найдовших серій. Покажи назву і тривалість у хвилинах (AS Хвилини), від найдовшої. Скільки хвилин триває №1?

Б3(+1) Своя загадка. Придумай 3–4 підказки, які разом ведуть рівно до одного рядка (серія, пісня або клієнт). Запиши підказки і запит, дай сусідові розгадати.
