Практична робота: Хмарні сервіси для організації колективної роботи

Час на виконання: 20–25 хвилин

Крок 1: Налаштування командного простору (7 хв)

  1. Об'єднайтеся в групи по 3–4 особи.
  2. Один із членів групи створює новий файл у Google Документах або дошку в Padlet / Miro.
  3. Надайте доступ іншим учасникам групи: одному з рівнем Редактор, іншому — Коментатор.

Крок 2: Одночасна робота та коментування (10 хв)

  1. Усі учасники одночасно заходять у файл.
  2. Редактори створюють коротку таблицю розподілу завдань для будь-якої події (наприклад, "Організація пікніка").
  3. Учасник з доступом Коментатор виділяє будь-який фрагмент тексту і залишає зауваження або запитання через кнопку «Додати коментар».
  4. Випробуйте згадування учасника через символ @ у коментарі.

Крок 3: Тест на витривалість: Історія версій (5 хв)

  1. Нехай один із редакторів навмисно видалить частину заповненої таблиці.
  2. Перейдіть у меню Файл ➔ Історія версій ➔ Переглянути історію версій.
  3. Знайдіть версію документа до видалення та відновіть її.

🔥 Завдання для тих, хто зробив швидше

Знайдіть у налаштуваннях документа режим «Пропонування» (Track Changes / Suggesting). Внесіть кілька правок так, щоб власник документа міг окремо підтвердити (прийняти) або відхилити кожну з ваших змін.
