3Граматика Python: 7 правил

Python, як і українська мова, має правила. Тільки людина зрозуміє речення з помилкою, а Python — ні: він зупиниться і покаже SyntaxError.

1. Великі й малі літери — різні

print, Print і PRINT — для Python три різні слова. Існує тільки перше.

✔ правильно
print('Привіт')
✘ NameError
Print('Привіт')

2. Текст — завжди в лапках, і лапки парні

Можна 'одинарні' або "подвійні", але відкрити й закрити однаковими. Якщо в тексті є апостроф (ім'я) — бери подвійні.

✔ правильно
input("Твоє ім'я: ")
✘ SyntaxError
input('Твоє ім'я: ')

3. Дужки — завжди парами

Скільки відкрив, стільки й закрий. Особливо уважно у вкладених функціях.

✔ правильно
age = int(input('Вік: '))
✘ SyntaxError: '(' was never closed
age = int(input('Вік: ')

4. Кома розділяє елементи й аргументи

У списку і в дужках функції. Числа пишемо без пробілів усередині.

✔ правильно
prices = [1199, 1249, 1899]
✘ SyntaxError
prices = [1 199, 1249 1899]

5. Після if / else — двокрапка, далі — відступ

Відступ (4 пробіли або Tab у Thonny) показує, які рядки належать до блоку. Без нього — IndentationError.

✔ правильно
if price < 500:
    print('Дешево')
✘ SyntaxError / IndentationError
if price < 500
print('Дешево')

6. = — це «поклади», а не «дорівнює»

Ліворуч — тільки ім'я змінної. Для порівняння «чи дорівнює?» в Python є == (знадобиться в if).

✔ правильно
months = age * 12
if age == 16:
✘ SyntaxError
age * 12 = months
if age = 16:

7. Імена змінних: латиниця, цифри, _

Не починати з цифри, без пробілів. І не займати імена функцій (min, print, input…).

✔ правильно
min_price = min(prices)
sale_price = 1499
✘ помилка або зламана функція
min = min(prices)
sale price = 1499
2price = 100

І бонус: усе після # — коментар. Python його ігнорує, він для людей: discount = round(x) # округлюємо до цілого

4Функції — потроху

У наших двох програмах уже є сім функцій. Функція — це готова «машинка»: даєш їй щось у дужках, вона щось робить і (часто) повертає результат.

minназва ( [5, 2, 9] )аргумент — що даємо → 2результат — що повертає

Як розпізнати функцію в коді: слово, а одразу за ним — дужки. Без дужок функція не запуститься.

Функції, які ми вже знаємо

ФункціяЩо дає на вхідЩо робить / повертаєПриклад → результат
print()будь-що, через комувиводить на екранprint('Hi', 5) → на екрані Hi 5
input()текст питаннячекає введення, повертає текстinput('Вік: ') → '16'
int()текст з цифрповертає ціле числоint('16') → 16
type()будь-яке значенняповертає типtype(16) → <class 'int'>
min()списокповертає найменшеmin([5, 2, 9]) → 2
round()число з комоюповертає округленеround(21.05) → 21
.index()значенняномер елемента в списку*prices.index(1249) → 1

* .index() пишеться через крапку після списку — така функція, «прикріплена» до об'єкта, називається методом.

Нові родичі — вони працюють так само

prices = [1199, 1249, 1899]
print(max(prices))   # 1899 — найбільше
print(sum(prices))   # 4347 — сума
print(len(prices))   # 3    — скільки елементів
print(str(21) + '%') # 21%  — число → текст (протилежність int)

Важливо: вкладені функції читаємо зсередини

print(round(sum(prices) / len(prices)))

① sum(prices) → 4347 · ② len(prices) → 3 · ③ ділимо → 1449.0 · ④ round → 1449 · ⑤ print виводить. Так ми порахували середню ціну одним рядком.

Зазирнемо вперед: свої функції

Функції можна створювати й самому — словом def. Наприклад, перевірку знижки можна «запакувати» в окрему машинку і перевіряти скільки завгодно товарів:

def is_honest(prices, sale_price):
    return sale_price < min(prices)

print(is_honest([1199, 1249, 1899], 1499))   # False
print(is_honest([1299, 1349, 1299], 999))    # True

Детально про def і return — на наступних уроках. Поки достатньо бачити: це той самий принцип «назва — аргументи — результат».

5Помилки в Thonny: як їх читати

Червоний текст у вікні Shell — це повідомлення від Python: де він зупинився і чому.

Анатомія помилки

Traceback (most recent call last): File "C:\Users\...\detector.py", line 5, in <module> old_price = prices[5] IndexError: list index out of range
1
line 5 — номер рядка. У Thonny це посилання: клацни — і курсор перескочить на цей рядок.
2
old_price = prices[5] — сам рядок, що зламався. Іноді під ним є ^^^^ — стрілочки показують точне місце.
3
IndexError — тип помилки. Одразу каже, яка це категорія проблеми.
4
list index out of range — пояснення: «індекс виходить за межі списку». Читай останній рядок першим!
Помічник у Thonny: меню View → Assistant (Вигляд → Помічник). Він пояснює помилку простішими словами й підказує, що перевірити.
