Інтернет-магазин: типи даних у Python

Ти відкриваєш власний інтернет-магазин. Усе, що в ньому є — назва, ціна, кількість, наявність, кольори — це дані, і в кожних даних є свій тип. Якщо переплутати тип, Python видасть помилку або, ще гірше, порахує неправильно.

Після практичної ти зможеш:

  • без підказки назвати 5 основних типів: int, float, str, bool, list;
  • за виглядом значення сказати, якого воно типу, і перевірити це через type();
  • передбачити, який тип вийде після +, *, / з різними типами, і чому інколи буде помилка.
Як працюємо. Усе робиш у Thonny, у двох файлах: shop.py (частини 1–3 і питання) та receipt.py (частина 4). Свої прогнози й пояснення пишеш коментарями — рядками, що починаються з #. Як їх ставити і які для цього клавіші — в кінці сторінки. Наприкінці показуєш вчителю обидва файли на екрані.
Перед кожним завданням є приклад із іншою темою. Дивись, як він зроблений, і роби так само зі своїми даними: копіювати приклад не можна.

Частина 1. Вгадай тип 3 бали

Приклад

Для кожного значення спочатку пишемо прогноз коментарем, потім рядок, що виводить тип. Запускаємо (F5) і дивимось, чи збігся прогноз:

# 1. прогноз: int
print(type(25))

# 2. прогноз: int
print(type('25'))

Python виведе:

<class 'int'>
<class 'str'>

Другий прогноз був неправильний. Тоді під ним дописуємо, чому:

# 2. прогноз: int
print(type('25'))
# помилився: це str, бо число в лапках — це текст

Завдання

Ось картка товару:

Навушники JBL
Ціна: 1499 · Рейтинг: 4.7
Артикул: '1499' · Є в наявності: True

У новому файлі shop.py зроби так, як у прикладі, для кожного з 8 значень. Якщо прогноз не збігся, допиши коментар: чому я помилився.

  1. 1499
  2. 4.7
  3. '1499'
  4. 'Навушники JBL'
  5. True
  6. 'True'
  7. ['чорний', 'білий']
  8. 0

Частина 2. Мій товар 3 бали

Приклад

Книжка в магазині. Для кожної характеристики створюємо змінну, а потім виводимо її значення і тип:

title = 'Кобзар'
price = 289.5
copies = 40
is_sale = False
tags = ['поезія', 'класика']

print(title, type(title))
print(price, type(price))
print(copies, type(copies))
print(is_sale, type(is_sale))
print(tags, type(tags))

Python виведе:

Кобзар <class 'str'>
289.5 <class 'float'>
40 <class 'int'>
False <class 'bool'>
['поезія', 'класика'] <class 'list'>

Зверни увагу: у змінної завжди одне ім’я англійською без пробілів, а в кожної з п’яти — свій тип.

Завдання

Придумай свій товар (не книжку і не навушники). Він не має повторюватись у класі: узгодь його з учителем. У цьому ж shop.py, нижче частини 1:

  1. Створи 5 змінних: назва, ціна з копійками, кількість на складі, чи є знижка, список із трьох кольорів або розмірів.
  2. Для кожної змінної виведи її значення і тип, як у прикладі.
  3. Усі п’ять типів мають бути різні.

Покажи вчителю: змініть разом одне значення так, щоб тип став іншим (наприклад, з int на str), і передбач, що виведе програма.

Частина 3. Що буде, якщо змішати типи 3 бали

Приклад

Результат дії теж має тип. Кладемо результат у змінну і виводимо її разом із типом. Перед цим, як завжди, прогноз:

# прогноз: 7, int
result = 3 + 4
print(result, type(result))

Python виведе 7 <class 'int'>. Тепер приклад із помилкою:

result = '5' + 3
print(result, type(result))

Python зупиниться з червоним повідомленням: TypeError: can only concatenate str (not "int") to str. Це значить: текст і число складати не можна. Щоб програма далі працювала, закоментуй цей рядок і поясни:

# result = '5' + 3
# print(result, type(result))
# TypeError: не можна скласти текст і число

Завдання

У shop.py, нижче частини 2, зроби так само для шести виразів. Для кожного: прогноз коментарем → результат і тип → якщо помилка, закоментуй рядки й напиши, чому вона.

  1. 3 + 4.0
  2. '3' + '4'
  3. '3' + 4
  4. '3' * 4
  5. 10 / 2
  6. 1499 * 2

Окремо одним коментарем відповідай: чому в пунктах 3 і 4 вийшло так по-різному?

Частина 4. Чек магазину 3 бали

Приклад

Чек для книжки. Усі дані — змінні, сума рахується з них, а біля кожного значення виводимо його тип:

title = 'Кобзар'
price = 289.5
copies = 2
total = price * copies

print('Товар:', title, type(title))
print('Ціна:', price, type(price))
print('Кількість:', copies, type(copies))
print('Разом:', total, type(total))

Python виведе:

Товар: Кобзар <class 'str'>
Ціна: 289.5 <class 'float'>
Кількість: 2 <class 'int'>
Разом: 579.0 <class 'float'>

Завдання

Створи новий файл receipt.py і зроби чек для свого товару з частини 2. У чеку має бути 6 рядків:

  1. товар,
  2. ціна,
  3. кількість (вигадай, скільки купують),
  4. знижка (bool),
  5. кольори або розміри (list),
  6. разом: ціна, помножена на кількість.

Біля кожного значення виведи його тип. Потім зміни кількість і ціну, запусти ще раз і переконайся, що «Разом» перерахувалось.

Питання наприкінці

Відповіді запиши коментарями в кінці shop.py, без запуску коду. Перевірити себе можна після.

  1. Який тип мають значення 3.0, '3', True, [3]?
  2. Чому '5' + 3 дає помилку, а '5' * 3 ні? Що вийде в другому випадку?
  3. Який тип у результату 2 + 3.5 і в результату 10 / 2?
  4. Чим відрізняються True і 'True'?
