Перша програма на Java

Сьогодні ти напишеш і запустиш свою першу Java-програму — прямо в браузері, без встановлення нічого зайвого.

→ Відкрити OneCompiler
1

Відкрий редактор

Перейди за посиланням вище. Ти побачиш готовий шаблон коду — не видаляй його одразу, спочатку натисни кнопку Run і подивись, що виведеться.

2

Напиши власне привітання

Заміни вміст файлу на код нижче — і встав своє ім'я замість Ім'я:

class Main {
    public static void main(String[] args) {
        System.out.println("Привіт, мене звати Ім'я!");
    }
}

Натисни Run. Якщо все правильно — текст з'явиться в панелі виводу праворуч (або знизу).

3

Додай ще рядки

Постав курсор перед закриваючою дужкою } методу main і додай ще 2–3 команди System.out.println(...), наприклад:

System.out.println("Я учень/учениця 10 класу.");
System.out.println("Мій улюблений предмет — ...");
System.out.println("Інформатику я обрав(-ла), бо ...");
Кожен рядок — окрема команда. Не забувай крапку з комою в кінці кожного рядка!
4

Зламай і полагодь

Навмисно приберіть одну крапку з комою або одну дужку — і натисніть Run. Прочитайте повідомлення про помилку: воно завжди вказує, у якому рядку проблема.

Поверніть символ на місце, щоб програма знову працювала.

✓

Перевір себе

  • Програма запускається без помилок
  • У виводі є моє ім'я
  • Є щонайменше 4 рядки виводу (println)
  • Я бачив(-ла), як виглядає повідомлення про помилку компіляції
class Main → метод main → System.out.println
