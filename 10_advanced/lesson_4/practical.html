Класифікація типів даних та структур для моделювання

10 клас · Інформатика

1. Тема уроку

Як описувати об’єкти реального світу за допомогою даних і правильно організовувати ці дані для комп’ютера.

2. Коротка теорія

Тип даних показує, що за значення ми зберігаємо і як із ним можна працювати.

ТипПрикладПриклад використання
Ціле число15вік, кількість, очки
Дійсне число72.5маса, температура, ціна
Текст"Anna"ім’я, назва, повідомлення
ЛогічнеTrue / Falseувімкнено/вимкнено, так/ні

Структура даних організовує кілька значень.

СтруктураПрикладІдея
Список["меч","щит","зілля"]елементи в певному порядку
Множина{"uk","en","pl"}унікальні елементи
Словник{"name":"Anna","age":15}пари «ключ → значення»
Модель даних — спрощене представлення об’єкта або процесу, у якому зберігаються потрібні для задачі характеристики.

3. Основні поняття

  • Дані — відомості, які можна зберігати та обробляти.
  • Тип даних — характеристика значення, що визначає його природу та допустимі операції.
  • Структура даних — спосіб організації набору значень.
  • Список — впорядкована колекція.
  • Множина — колекція унікальних елементів.
  • Словник — набір пар «ключ → значення».
  • Модель — спрощене представлення реального об’єкта для певної задачі.

4. Сучасні приклади

  • Гра: персонаж має ім’я, рівень, кількість монет, стан і список предметів.
  • Смартфон: контакт має ім’я, номер, пошту та групи.
  • Робот: сенсори дають числа, стан може бути True/False, команди можна зберігати списком.
  • Соціальна мережа: профіль, дописи, реакції та підписки — структуровані дані.
  • AI: дані перед обробкою подаються у формах, придатних для обчислень.

5. Практична робота

Для запуску Python у браузері можна використати Programiz Online Python Compiler. Для покрокового перегляду виконання — Python Tutor.

1Розпізнай типи

name = "Anna"
age = 15
height = 1.67
online = True

print(type(name))
print(type(age))
print(type(height))
print(type(online))

Запусти код і визнач, який тип має кожне значення.

Подумай: чим відрізняються 15 і 15.0?

2Створи модель профілю

student = {
    "name": "Anna",
    "age": 15,
    "favorite_subject": "informatics",
    "online": True,
    "scores": [10, 11, 12]
}

print(student["name"])
print(student["scores"])

Зміни ім’я, вік і предмет. Додай ще один ключ. Зміни список оцінок.

Подумай: який тип має scores? Чому student містить різні типи даних?

3Обери структуру

Для кожної ситуації запиши: список / множина / словник.

  1. Черга пісень, які відтворюються по порядку.
  2. Набір унікальних мов інтерфейсу.
  3. Характеристики ноутбука: бренд, RAM, процесор.
  4. Інвентар персонажа гри.

Подумай: чому для характеристик ноутбука зручно використовувати ключі?

4Створи власну модель

Обери смартфон, автомобіль, персонажа гри, робота або відео.

Запиши 5 властивостей. Для кожної вкажи тип даних. Одну властивість зроби списком.

Приклад: робот → ім’я — текст; заряд — число; активний — логічне; температура — число; сенсори — список.

6. Самостійна робота

  1. Що таке тип даних?
  2. Який тип підходить для температури 21.5?
  3. Чим список відрізняється від множини?
  4. Коли зручно використовувати словник?
  5. Що таке модель даних?
  6. Чи може словник містити список?

7. Додаткове завдання

Створи модель персонажа гри з 6 властивостями. Використай щонайменше 3 різні типи даних і 2 структури даних.

8. Що треба запам’ятати

  1. Тип даних описує, що це за значення.
  2. Структура даних описує, як організувати багато значень.
  3. Числа, текст і логічні значення використовуються для різних задач.
  4. Список зручний, коли важливі елементи та їх порядок.
  5. Множина зручна, коли потрібні унікальні елементи.
  6. Словник зручний для зв’язків «ключ → значення».
  7. Хороша модель містить не все підряд, а лише дані, потрібні для конкретної задачі.
