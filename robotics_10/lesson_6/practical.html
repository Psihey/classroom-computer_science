🚦 Пішохідний світлофор з кнопкою

Минулого разу кнопка вмикала маячок. Сьогодні збираємо справжній пристрій із вулиці: світлофор для машин, який перемикається, коли пішохід натискає кнопку, і пищить, поки можна переходити.

🎯 Що будуємо

У звичайному стані машинам горить зелений. Пішохід натискає кнопку, і світлофор проходить такі кроки:

🔊 Навіщо звук? Справжні пішохідні світлофори пищать, щоб дорогу могли безпечно перейти незрячі люди. Ми робимо те саме.

🆕 Що нового сьогодні

1. Імена для пінів: const int

Коли світлодіодів три, легко заплутатися, що таке пін 10, а що 12. Тому даємо пінам імена, як контактам у телефоні: ти ж шукаєш «Мама», а не номер.

const int RED = 12;      // червоний на піні 12
const int YELLOW = 11;   // жовтий на піні 11
const int GREEN = 10;    // зелений на піні 10

digitalWrite(RED, HIGH);   // читається як «увімкни червоний»
✅ Переставили світлодіод на інший пін? Змінюєш одне число вгорі, а не шукаєш його по всьому коду.
const означає «константа»: це значення не змінюється під час роботи програми.

2. Пʼєзо-пищалка: tone() і noTone()

Пʼєзоелемент — маленька «колонка». Arduino дуже швидко вмикає й вимикає пін, пластинка всередині тремтить, і ми чуємо звук.

tone(BUZZER, 1000);   // почати пищати на частоті 1000 Гц
noTone(BUZZER);        // замовкнути
ЧастотаЯк звучить
262нота «до»: низько, спокійно
440нота «ля»: так налаштовують гітару
1000різкий писк, добре чутно на вулиці
⚠️ tone() пищить, доки не скажеш noTone(). Забув noTone, і світлофор пищатиме вічно 😅

3. Кожному світлодіоду свій резистор

Як і минулого разу: пін → резистор 220 Ω → анод (довга, зігнута ніжка) → катод → GND. Тепер таких кіл три. Усі катоди сходяться на спільну лінію GND (лінія «−» уздовж краю макетної плати).

🔌 Схема підключення

Спрощена схема: лінії праворуч від кожного елемента йдуть до чорної лінії GND (на макетній платі це лінія «−»). У світлодіода до GND іде катод (коротка пряма ніжка).

🔴 Червоний LEDпін 12 → резистор → анодкатод → GND
🟡 Жовтий LEDпін 11 → резистор → анодкатод → GND

🛠️ Збираємо світлофор крок за кроком

Працюй у Tinkercad Circuits. Після кожного кроку звіряйся з рядком «Має вийти». Не виходить? Подивись «Типові помилки» вище. В останньому кроці ти звіриш свою схему з готовою схемою-зразком.

Одразу до кроків ↓ ↑ До пояснення Бланк відповідей

🧱 Частина 1. Три світлодіоди

1

Відкрий tinkercad.com → Circuits → Create new Circuit. Назви проєкт «Світлофор Прізвище».

💡 Можна зробити копію минулого проєкту («Маячок з кнопкою»): у списку проєктів ⚙️ → Duplicate. Тоді Arduino, макетна плата і кнопка вже будуть на місці.

Порожнє робоче поле (або копія маячка) з твоєю назвою.

2

Постав Arduino Uno R3 і поруч Breadboard Small (макетну плату).

🧩 Навіщо макетна плата? Щоб зʼєднувати деталі без паяльника. Усередині під дірочками сховані металеві смужки, і деталі, встромлені в одну смужку, зʼєднуються між собою. Запамʼятай два правила:
  1. Стовпчик із 5 дірочок (a–e в одній колонці) — це один провідник. Встромиш дві ніжки в колонку 4, і вони зʼєднані, хоча не торкаються.
  2. Довга лінія вздовж краю зі знаком − — теж один провідник на всю довжину. Підключимо її до GND Arduino, і всі «мінуси» будуть в одному місці.
Жолобок посередині розділяє плату на дві половини, які не зʼєднані.

💡 Наведи мишку на дірочку в Tinkercad: підсвітяться всі дірочки, зʼєднані з нею. Так легко перевірити себе.

На робочому полі стоять Arduino і макетна плата.

3

Червоний світлодіод. Збери одне коло точно як на малюнку, а потім повториш його ще двічі.

  1. Постав світлодіод, клацни на нього і в полі Color обери Red. Встром ніжки в рядок e: катод (пряма ніжка) у колонку 3, анод (зігнута) у колонку 4.
  2. Постав резистор і встанови 220 Ω. Ліву ніжку встром у c4, тобто в ту саму колонку, що й анод. Права ніжка стане приблизно в c8.
  3. Дріт від піна 12 Arduino до e8 (колонка правої ніжки резистора).
  4. Дріт від a3 (колонка катода) вниз до лінії − під рядком a.
  5. Дріт від GND Arduino (внизу, біля POWER) до тієї ж лінії −. Цей дріт потрібен один на всю плату.
🔁 Шлях струму: пін 12 → дріт → колонка 8 → резистор → колонка 4 → анод → світлодіод → катод → колонка 3 → дріт → лінія − → GND. Коло замкнулося!

Тепер так само жовтий і зелений, тільки правіше:

LEDКатод (пряма)Анод (зігнута)РезисторДріт від ArduinoДріт до −
🔴 червонийe3e4c4 → c8пін 12 → e8a3 → −
🟡 жовтийe11e12c12 → c16пін 11 → e16a11 → −
🟢 зеленийe19e20c20 → c24пін 10 → e24a19 → −

Права ніжка резистора стала не в ту колонку? Не страшно: просто веди дріт від піна в ту колонку, де вона опинилася. Головне, щоб у тій колонці не було інших ніжок. Колонки 26–30 залиш вільними для кнопки.

Три однакові кола. Наведи мишку на анод кожного LED: має підсвітитися колонка з ніжкою резистора.

4

Відкрий Code → Text (погодься замінити блоки). Встав Код 1 і натисни Start Simulation.

Код 1. Автоматичний світлофор (перевірка схеми)
// Імена для пінів
const int RED = 12;
const int YELLOW = 11;
const int GREEN = 10;

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
}

void loop() {
  digitalWrite(GREEN, HIGH);   // зелений
  delay(3000);
  digitalWrite(GREEN, LOW);

  digitalWrite(YELLOW, HIGH);  // жовтий
  delay(1000);
  digitalWrite(YELLOW, LOW);

  digitalWrite(RED, HIGH);     // червоний
  delay(3000);
  digitalWrite(RED, LOW);
}

По колу: зелений 3 с → жовтий 1 с → червоний 3 с. Кожен світлодіод загоряється. Якщо якийсь ні, переверни його.

🔘 Частина 2. Кнопка і пищалка

5

Зупини симуляцію. Постав кнопку над жолобком у вільних колонках праворуч (26–30), як минулого разу. Одну ніжку зʼєднай дротом із піном 2, а протилежну по діагоналі — з лінією − (це теж GND).

Кнопка стоїть над жолобком, підключені пін 2 і GND по діагоналі.

6

Знайди в компонентах Piezo і постав поруч із платою (на саму плату не обовʼязково). Наведи мишку на ніжки й підключи дротами: Positive (+) → пін 8, Negative (−) → лінія − на макетній платі.

Пищалка підключена до піна 8 і GND.

7

Заміни код на Код 2 і запусти симуляцію. Увімкни звук у браузері 🔊.

Код 2. Пішохідний світлофор
const int RED = 12;
const int YELLOW = 11;
const int GREEN = 10;
const int BUTTON = 2;
const int BUZZER = 8;

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BUZZER, OUTPUT);
  pinMode(BUTTON, INPUT_PULLUP);   // кнопка, як на минулому уроці
}

void loop() {
  digitalWrite(GREEN, HIGH);       // звичайний стан: машинам зелений

  if (digitalRead(BUTTON) == LOW) {   // пішохід натиснув кнопку
    delay(1000);                       // світлофор «думає»
    digitalWrite(GREEN, LOW);

    digitalWrite(YELLOW, HIGH);        // жовтий
    delay(1500);
    digitalWrite(YELLOW, LOW);

    digitalWrite(RED, HIGH);           // машинам червоний, пішоходи йдуть
    tone(BUZZER, 1000);               // звук для незрячих пішоходів
    delay(5000);
    noTone(BUZZER);
    digitalWrite(RED, LOW);

    digitalWrite(YELLOW, HIGH);        // знову жовтий
    delay(1500);
    digitalWrite(YELLOW, LOW);
  }
}

Горить зелений. Натиснув кнопку: через 1 с жовтий, потім червоний і писк 5 с, потім жовтий, і знову зелений. Без натискання нічого не змінюється.

8

Звір свою схему зі зразком. Подивись на схему-зразок і порівняй її зі своєю схемою в Tinkercad.

Перевір по черзі:

  1. Пін 12 → дріт → колонка 8 → резистор → анод червоного (колонка 4).
  2. Пін 11 → колонка 16 → резистор → анод жовтого (колонка 12).
  3. Пін 10 → колонка 24 → резистор → анод зеленого (колонка 20).
  4. Катоди (колонки 3, 11, 19) → дроти → нижня лінія −.
  5. GND Arduino → нижня лінія −.
  6. Кнопка: пін 2 і лінія − по діагоналі, кнопка над жолобком. Пищалка: «+» → пін 8, «−» → лінія −.

Усі пункти збігаються, світлофор працює як у кроці 7.

9

Покажи вчителю запущену симуляцію: натисни кнопку і пройди весь цикл світлофора.
