Маячок, що вмикається кнопкою

Доробляємо блимаючий світлодіод і вчимо плату Arduino «слухати» кнопку в симуляторі Tinkercad.

🛠️ Перейти до практичної роботи ↓

🎯Що ти засвоїш сьогодні

  • Зібрати в Tinkercad схему зі світлодіодом через резистор на пін 13 і запустити програму блимання.
  • Підключити кнопку до піна 2 і прочитати її стан командою digitalRead з режимом INPUT_PULLUP.
  • Використати умову if/else, щоб світлодіод блимав лише під час натискання кнопки.

💡Що потрібно зрозуміти

  • Пін плати може бути виходом (OUTPUT) — керує світлодіодом, або входом (INPUT) — «слухає» кнопку.
  • Світлодіод завжди підключаємо через резистор, інакше він може перегоріти.
  • З режимом INPUT_PULLUP натиснута кнопка дає LOW, а відпущена — HIGH.
  • Умова if/else дозволяє програмі вирішувати: якщо кнопку натиснуто — блимати, інакше — не світитися.
  • Так працюють кнопка аварійки, кнопка виклику ліфта і дверний дзвоник з підсвіткою.

Що таке Arduino простими словами

Arduino — це маленька плата з мікроконтролером, тобто крихітним комп'ютером, який виконує одну програму знову і знову. По краях плати є піни — металеві контакти з номерами. До них підключають світлодіоди, кнопки, датчики, моторчики.

Кожен пін може працювати у двох ролях:

Роль Що робить Приклад
Вихід, OUTPUT Плата подає напругу і керує пристроєм Увімкнути світлодіод
Вхід, INPUT Плата «слухає» і дізнається стан Чи натиснута кнопка

Світлодіод і резистор

Світлодіод світиться, коли через нього йде струм. У нього дві ніжки: довша (плюс, анод) і коротша (мінус, катод). У Tinkercad анод — це ніжка із загином. Анод підключаємо до піна 13 через резистор 220 Ом, катод — до GND (земля, мінус). Резистор обмежує струм, без нього світлодіод може перегоріти.

Кнопка і режим INPUT_PULLUP

Кнопка замикає коло, поки її тримають. Ми підключаємо одну ніжку кнопки до піна 2, а протилежну по діагоналі — до GND. У програмі пишемо pinMode(2, INPUT_PULLUP);. Це вмикає всередині плати спеціальний резистор, і тоді:

  • кнопку відпущено → digitalRead(2) дає HIGH;
  • кнопку натиснуто → digitalRead(2) дає LOW.

Так, це здається навпаки, але запам'ятай: натиснуто = LOW.

Як працює програма покроково

Програма Arduino має дві частини:

  1. setup() — виконується один раз на початку: тут кажемо, який пін вихід, а який вхід.
  2. loop() — повторюється безкінечно: тут плата перевіряє кнопку і вирішує, що робити.
void setup() {
  pinMode(13, OUTPUT);
  pinMode(2, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);
    delay(300);
    digitalWrite(13, LOW);
    delay(300);
  } else {
    digitalWrite(13, LOW);
  }
}

Читаємо як речення: якщо кнопку натиснуто — увімкнути світлодіод, почекати 0,3 с, вимкнути, почекати 0,3 с; інакше — тримати світлодіод вимкненим.

Навіщо це в житті

Майже кожен пристрій навколо працює так само: щось «чує» (кнопку, датчик) і на це реагує (світлом, звуком, рухом). Кнопка аварійки в машині вмикає блимання поворотників, кнопка ліфта засвічується після натискання, кнопка пішохідного переходу перемикає світлофор.

Типові пастки

  • Подвійне ==. У порівнянні пишемо ==, а не =. Один знак = означає «присвоїти», і умова працюватиме неправильно.
  • Не та пара ніжок кнопки. Якщо світлодіод блимає завжди або ніколи — перепідключи провід GND до ніжки кнопки по діагоналі від піна 2.
  • Світлодіод перевернуто. Якщо він не світиться зовсім — перевір, що ніжка із загином (анод) іде до резистора і піна 13.
  • Крапка з комою. Кожна команда закінчується ;, інакше програма не запуститься.

Розібрані приклади

Приклад 1. Просте блимання без кнопки

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
  1. У setup() пін 13 стає виходом — плата може ним керувати.
  2. У loop() світлодіод вмикається (HIGH), 1000 мс = 1 секунда чекаємо.
  3. Вимикаємо (LOW), знову чекаємо секунду.
  4. loop() починається спочатку, і так безкінечно.

Результат: світлодіод блимає раз на дві секунди. Це той маячок, який ми починали минулого уроку.

Приклад 2. Кнопка вмикає світло без блимання

void setup() {
  pinMode(13, OUTPUT);
  pinMode(2, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
  1. Пін 2 стає входом з підтягуванням: відпущена кнопка — HIGH, натиснута — LOW.
  2. У loop() плата весь час питає: «Пін 2 зараз LOW?»
  3. Якщо так — світлодіод горить постійно.
  4. Якщо ні (else) — світлодіод вимкнено.

Результат: світлодіод світиться рівно стільки, скільки тримаєш кнопку, — як дверний дзвоник з підсвіткою. На практичній ми замість постійного світіння вставимо блимання.

Приклад 3. Помилка: один знак = в умові

if (digitalRead(2) = LOW) {
  digitalWrite(13, HIGH);
}
  1. Один знак = означає «записати значення», а не «порівняти».
  2. Компілятор видасть помилку або програма поведеться не так, як задумано.
  3. Правильно: digitalRead(2) == LOW — два знаки рівності.

Висновок: якщо в умові if щось порівнюєш — завжди ==.

🌍Аналогії та приклади з життя

  • Пін-вихід — як рот: плата щось «каже» світу (вмикає світло). Пін-вхід — як вухо: плата «слухає», що відбувається.
  • Резистор — як кран на трубі: він зменшує потік струму, щоб світлодіод не «захлинувся» і не перегорів.
  • Кнопка — як двері: відчинили (натиснули) — струм проходить, зачинили (відпустили) — не проходить.
  • Умова if — як охоронець біля входу: якщо в тебе є перепустка, проходиш, інакше — ні.
  • Функція loop() — як годинник, що безкінечно цокає: плата знову і знову перевіряє кнопку тисячі разів на секунду.

Мета: у симуляторі Tinkercad зробити маячок, яким керує кнопка, як аварійкою в машині.

Що буде в результаті: на екрані плата Arduino, світлодіод і кнопка. Натискаєш і тримаєш кнопку мишкою, і світлодіод блимає. Відпускаєш, і він не світиться.

Як працювати:

  • Роби кроки по черзі, не перестрибуй.
  • Після кожного кроку подивись на рядок «Що має вийти». Якщо в тебе так само, переходь далі. Якщо ні, виправ або поклич вчителя.
  • Код писати не треба: скопіюй його із заготовки і встав.
  • В останньому кроці ти звіриш свою схему з готовою схемою-зразком.

Корисні дії в Tinkercad:

  • Помилився, тоді натисни Ctrl + Z, і остання дія скасується.
  • Щоб видалити деталь чи провід, клацни на нього і натисни Delete.
  • Щоб повернути деталь, клацни на неї і натисни R.
  • Проєкт зберігається сам, нічого натискати не треба.

  1. Відкрий Tinkercad і створи нову схему

    1. Відкрий сайт tinkercad.com і увійди у свій акаунт, так само як минулого уроку.
    2. Ліворуч натисни Схеми (англійською Circuits).
    3. Натисни кнопку Створити, потім обери Схема.
    4. Угорі ліворуч є дивна назва проєкту з випадкових слів. Клацни на неї, зітри і напиши Маячок з кнопкою Прізвище. Натисни Enter.

    Якщо минулого уроку ти вже поставив плату і світлодіод, відкрий той проєкт і переходь одразу до кроку 3.

    Має вийти: Посередині порожнє біле поле, праворуч список деталей, угорі ліворуч твоя назва проєкту.

  2. Постав плату Arduino і макетну плату

    1. Праворуч угорі є поле пошуку деталей. Введи туди Arduino.
    2. Знайди деталь Arduino Uno R3 (синя плата). Натисни на неї, перенеси на поле і клацни, щоб поставити.
    3. У пошуку введи Макетна і так само постав Макетна плата мала (англійською Breadboard Small) поруч з Arduino, праворуч від неї.

    Що таке макетна плата: це біла дошка з дірочками. Дірочки в одному стовпчику з'єднані між собою, як один провід. Наведи мишку на будь-яку дірочку, і Tinkercad підсвітить зеленим, які дірочки з нею з'єднані.

    Має вийти: На полі стоять синя плата Arduino і біла макетна плата поруч.

  3. Постав світлодіод і резистор

    1. У пошуку введи Світлодіод і постав червоний світлодіод на макетну плату, у верхню половину. Його дві ніжки мають потрапити в дві різні дірочки.
    2. Знайди у світлодіода ніжку із загином. Це плюс, він називається анод. Пряма ніжка — мінус, катод.
    3. У пошуку введи Резистор і постав його на макетну плату так, щоб один його кінець був у тому самому стовпчику, що й ніжка із загином. Перевір: наведи мишку на кінець резистора, і зеленим має підсвітитися стовпчик разом з ніжкою світлодіода.
    4. Клацни на резистор. З'явиться маленьке віконце. У полі Опір напиши 220, а поруч обери одиниці Ω (не kΩ).

    Має вийти: На макетній платі стоять світлодіод і резистор 220 Ω. Резистор торкається того стовпчика, де ніжка світлодіода із загином.

  4. З'єднай світлодіод з платою проводами

    Провід малюється так: клацни на початок, потім клацни на кінець. Тягнути не треба.

    1. Наведи мишку на пін 13 угорі плати Arduino (номери підписані біля дірочок). Клацни.
    2. Клацни на дірочку в стовпчику другого кінця резистора (не того, що біля світлодіода). Провід готовий.
    3. Клацни на дірочку в стовпчику прямої ніжки світлодіода (катод).
    4. Клацни на пін GND на Arduino (поруч з піном 13 є GND). Провід готовий.
    5. Щоб не плутатися, зміни кольори: клацни на провід і обери колір. Для піна 13 — червоний, для GND — чорний.

    Перевір себе по ланцюжку: пін 13 → резистор → ніжка із загином → пряма ніжка → GND. Кожен кінець проводу має стояти в дірочці, а не висіти в повітрі.

    Має вийти: Два проводи: червоний від піна 13 до резистора, чорний від прямої ніжки світлодіода до GND.

  5. Запусти блимання без кнопки

    1. Угорі праворуч натисни кнопку Код. Відкриється вікно з кольоровими блоками.
    2. Угорі цього вікна є список, де написано Блоки. Клацни на нього й обери Текст.
    3. З'явиться попередження. Натисни Продовжити.
    4. Клацни в код, натисни Ctrl + A (виділити все) і Delete (видалити).
    5. Скопіюй із заготовки Код 1 і встав його: Ctrl + V.
    6. Угорі праворуч натисни Почати моделювання.

    Має вийти: Світлодіод блимає: півсекунди світиться, півсекунди ні. Маячок з минулого уроку готовий. Натисни **Зупинити моделювання** (та сама кнопка).

  6. Постав кнопку на макетну плату

    1. У пошуку деталей введи Кнопка (англійською Pushbutton). Це квадратик з чотирма ніжками.
    2. Постав кнопку посередині макетної плати, над жолобком (широка смужка без дірочок посередині). Дві ніжки мають бути вище жолобка, дві — нижче.
    3. Запам'ятай головне правило: дроти підключаємо до двох ніжок навскоси, по діагоналі. Наприклад, ліва верхня і права нижня.

    Чому так: всередині кнопки ніжки з'єднані парами. Якщо взяти ніжки по діагоналі, кнопка точно працюватиме.

    Має вийти: Кнопка стоїть посередині макетної плати над жолобком, ти обрав дві ніжки по діагоналі.

  7. Підключи кнопку до піна 2 і GND

    1. Клацни на пін 2 угорі плати Arduino, потім клацни на дірочку біля лівої верхньої ніжки кнопки (у тому самому стовпчику). Зроби цей провід жовтим.
    2. Клацни на дірочку біля правої нижньої ніжки кнопки, потім клацни на будь-який GND на Arduino. Зроби цей провід чорним.
    3. Більше нічого не додавай. Резистор для кнопки не потрібен, його замінить команда в коді.

    Має вийти: Від піна 2 жовтий провід іде до лівої верхньої ніжки кнопки, від правої нижньої ніжки чорний провід іде до GND. Світлодіод підключений, як і раніше.

  8. Встав код з кнопкою

    1. Якщо моделювання ще йде, зупини його.
    2. Відкрий Код, натисни Ctrl + A і Delete, щоб видалити Код 1.
    3. Скопіюй із заготовки Код 2 і встав його.
    4. Знайди в коді три місця і перевір їх очима:
      • є рядок pinMode(2, INPUT_PULLUP);
      • у рядку з if стоять два знаки рівності: ==
      • кожна команда закінчується крапкою з комою ;

    Слова після // — це пояснення для людини. Плата їх не читає.

    Має вийти: У вікні Код 2, жодних червоних позначок помилок.

  9. Перевір маячок кнопкою

    1. Натисни Почати моделювання.
    2. Нічого не чіпай і порахуй до трьох. Світлодіод не світиться.
    3. Наведи мишку на кнопку, натисни і не відпускай ліву кнопку мишки. Світлодіод блимає.
    4. Відпусти. Світлодіод гасне (може ще раз блимнути, це нормально).

    Якщо не так:

    • Блимає завжди, навіть без натискання → дроти на кнопці не по діагоналі. Перестав чорний провід на іншу нижню ніжку.
    • Не світиться ніколи, а маленький вогник L на платі блимає → світлодіод перевернуто. Видали його і постав навпаки.
    • Нічого не відбувається → дивись, чи кожен кінець проводу стоїть у дірочці.
    • Код не запускається → знайди, де забута ; або один =.

    Має вийти: Маячок готовий: блимає, лише поки тримаєш кнопку, і не світиться, коли відпустив. Зупини моделювання.

  10. Зміни швидкість блимання

    1. Відкрий Код. Знайди два числа 300 в рядках з delay.
    2. Заміни обидва на 100. Запусти моделювання і натисни кнопку.
    3. Тепер спробуй 600. Подивись, що змінилося.
    4. Залиш число, яке тобі подобається найбільше, і зупини моделювання.

    Число в delay — це пауза в мілісекундах. 1000 мілісекунд = 1 секунда.

    Має вийти: З числом 100 маячок блимає швидко, з 600 повільно. Ти можеш пояснити, що робить число в delay.

  11. Звір свою схему зі зразком

    Подивись на схему-зразок і порівняй її зі своєю схемою в Tinkercad.

    !Схема Arduino Uno з кнопкою на піні 2 і світлодіодом на піні 13

    Перевір по черзі:

    1. Від піна 13 провід іде до резистора, а резистор — до ніжки із загином світлодіода.
    2. Пряма ніжка світлодіода з'єднана з GND.
    3. Від піна 2 провід іде до однієї ніжки кнопки.
    4. Ніжка кнопки по діагоналі з'єднана з GND.
    5. Кнопка стоїть над жолобком посередині макетної плати.

    Кольори проводів і точне місце деталей на макетній платі можуть трохи відрізнятися — це нормально. Головне, щоб усі з'єднання були такі самі. Якщо щось не збігається, виправ це місце, знову запусти моделювання і перевір кнопкою.

    Має вийти: Усі з'єднання у твоїй схемі збігаються зі зразком, а маячок блимає лише під час натискання кнопки. Покажи роботу вчителю.

Заготовка — скопіюй собі

Код 1 — блимання без кнопки (крок 5)

void setup() {
  pinMode(13, OUTPUT);       // пін 13 - вихід, світлодіод
}

void loop() {
  digitalWrite(13, HIGH);    // увімкнути
  delay(500);                // почекати 0,5 с
  digitalWrite(13, LOW);     // вимкнути
  delay(500);                // почекати 0,5 с
}

Код 2 — маячок з кнопкою (крок 8)

void setup() {
  pinMode(13, OUTPUT);       // пін 13 - вихід, світлодіод
  pinMode(2, INPUT_PULLUP);  // пін 2 - вхід, кнопка
}

void loop() {
  if (digitalRead(2) == LOW) {   // якщо кнопку натиснуто
    digitalWrite(13, HIGH);      // увімкнути
    delay(300);                  // почекати
    digitalWrite(13, LOW);       // вимкнути
    delay(300);                  // почекати
  } else {                       // інакше
    digitalWrite(13, LOW);       // не світити
  }
}

Що здати: Показати вчителю запущену симуляцію в Tinkercad: світлодіод блимає лише під час натискання кнопки, а схема збігається зі схемою-зразком. Проєкт називається «Маячок з кнопкою Прізвище».

⭐ Додаткове завдання: Поліцейська мигалка

Перетвори маячок на поліцейську мигалку: додай другий світлодіод (синій) на пін 12 через свій резистор 220 Ом. Коли кнопку натиснуто, світлодіоди мають блимати по черзі: червоний горить — синій ні, потім навпаки. Коли кнопку відпущено — обидва не світяться.

Підказка: другий світлодіод підключається так само, як перший, тільки до піна 12. У setup() не забудь зробити пін 12 виходом.
